util/ — 여러 사이클에서 공용으로 import되는 파일

배치 기준: 자기 사이클 폴더 밖의 파일이 import하는 모듈은 전부 여기로 모았다.
util 내부 파일끼리만 서로 의존하므로(외부 의존 0), util은 자기완결적이다.
파일명은 원래 사이클 접두사(vNN_)를 그대로 유지했다 — docs/version.md의 기록과
대조할 수 있도록 하기 위함이다. 아래 "출처"가 그 사이클을 가리킨다.

LPneuroBLS_v7.py                                                    [출처: v7]
--------------------------------------------------------------------------------
  프로젝트 전체의 공유 코어. 거의 모든 스크립트가 이 파일을 import한다.
  제공하는 것:
    FastBinaryEnv        부분배정 상태 + 제약 전파(propagate_constraints) +
                         probing(apply_probing). step_inplace로 변수 고정.
    solve_lp_relaxation  SCIP 기반 LP 완화 풀이. (x_lp, 성공여부) 반환.
    kernel_pump_stats    영공간 교대투영(kernel pump). LP 해에서 출발해 정수해로
                         수렴 시도. (x, 성공여부, 통계) 반환.
    BipartiteGNN         v5~v12에서 쓰던 다중헤드 GNN
                         (selection/assign/value/feasibility 4헤드, hidden 256, 8층).
                         v15 이후로는 MarginalNet(v15_train_marginal.py)에 밀려
                         성능 비교용 baseline 역할만 한다.
    policy_dfs           정책 안내 완전 백트래킹. node_budget으로 예산 제한.
                         'solved' / 'infeasible' / 'budget' 3상태 반환.
    Trainer              전문가 모방 학습 루프(run_expert_imitation 등).

lattice_enum.py                                                     [출처: v8]

generate_hard_instances.py                                          [출처: v12]
--------------------------------------------------------------------------------
  고난도 인스턴스 생성기. 핵심 함수 gen_hard_feasible(m, n, rng, K).
  동일한 A에 대해 후보 해 K개를 심어보고 vertex_spread가 가장 큰 것을 채택한다
  (= LP 완화 폴리토프를 직접 크게 만들어 LP 신호를 약화시킨다).
  유일해 가정을 두지 않는다. v15/v22의 |S| 통제 실험이 이 생성기의 m을 조절해 수행된다.

v13_pipeline.py                                                     [출처: v13]
--------------------------------------------------------------------------------
  기여율 0%로 실측된 단계(GNN feasibility 판단 / MCTS / DFS의 해탐색 역할)를 제거한
  순수 심볼릭 파이프라인. 남긴 단계: 제약 전파, LP hard rule, kernel pump, AHL/BKZ,
  DFS(infeasibility 증명 전용).
  주요 함수:
    ahl_try_with_perm(A, b, perm, block)  주어진 열 순열로 AHL/BKZ 1회 시도.
                                          검증된 0/1 해만 반환. v14/v22도 이것을 쓴다.
    sample_perm / perm_logprob            Plackett-Luce 순열 분포 (Gumbel top-k).
    solve_instance                        위 단계들을 순서대로 실행하는 진입점.

v14_core.py                                                         [출처: v14]
--------------------------------------------------------------------------------
  변수 고정을 통한 차원 축소 도구.
    reduce_instance      고정 변수를 소거해 축소 인스턴스 (A', b') 생성.
    bound_reject         공짜 필요조건 검사(b<0 또는 b>rowsum이면 즉시 폐기).
    lp_reject            축소 LP가 infeasible인지 검사(약 3~10ms).
    ahl_on_reduced       축소 인스턴스에 AHL 시도.
    lp_confidence_fixing LP 신뢰도 상위 k개 고정(고전 baseline).
    gnn_marginals        사전학습 GNN의 변수별 P(x_j=1) 추출.
    topT_joint_fixings   결합확률 상위 T개 패턴을 순서대로 열거. i.i.d. 샘플링이
                         과신한 예측기에서 같은 답만 반복하는 문제를 해결한다.
    solve_with_fixing    고정 -> 싼 기각검사 -> AHL 재시도 루프.

v15_bayes_limit.py                                                  [출처: v15]
--------------------------------------------------------------------------------
  해집합 S를 CP-SAT로 전수열거하고 베이즈 상한을 계산한다.
    enumerate_solutions(A, b, cap, time_limit) -> (S, complete)
  ** 중요 **: complete 판정은 OPTIMAL 또는 INFEASIBLE일 때만 True다.
  CP-SAT의 FEASIBLE은 "시간제한으로 중단됐으나 해를 일부 수집"을 뜻하므로 완료가 아니다.
  이것을 완료로 처리하면 잘린 해집합으로 계산한 편향된 주변확률이 정답 라벨로 들어간다
  (2026-09-10에 실제로 발생했던 버그이며, n=100 측정치를 전부 오염시켰다).

v15_train_marginal.py                                               [출처: v15]
--------------------------------------------------------------------------------
  주변확률 예측 전용 소형 모델과 학습 루프. v17 이후 모든 사이클이 이것을 쓴다.
    MarginalNet   변수/제약 이분 GNN. 변수 특징 3개(LP값, 열차수, LP소수부),
                  제약 특징 3개(b/rowsum, rowsum/n, LP잔차), GAT 메시지패싱 4라운드,
                  변수당 로짓 1개 출력. hidden 64, 4층 — 기존 BipartiteGNN(256/8층,
                  4헤드)보다 훨씬 작지만 top-3 정확도에서 15%p 앞선다.
    featurize     레코드(A, b, x, marginals)를 텐서 입력으로 변환.
    train_arm     하드 라벨(x*) / 소프트 라벨(주변확률) 중 선택해 학습.
    evaluate      양쪽 타겟 모두로 채점(자기 목적함수로만 이기는 것을 방지).

v18_probing_recall.py                                               [출처: v18]
--------------------------------------------------------------------------------
  probing(반대값을 넣어 모순이면 원래 값이 강제됨)의 회수율 측정 + 함수 제공.
    prop_probe(A, b, j, val)  반대값 배정 후 전파로 모순 검출. 재현율 3~16%로 약하다.
    lp_probe(A, b, j, val)    반대값 배정 후 LP 완화가 infeasible인지 검사.
                              재현율 62~79%, 변수당 약 2.2ms. v20의 lp_probe arm이 쓴다.
  단독 실행하면 깊이별 FORCED 변수 회수율 표를 출력한다.

v20_guided_search.py                                                [출처: v20]
--------------------------------------------------------------------------------
  분기 안내 품질 비교용 DFS 탐색 루프와 안내 전략 모음.
    GUIDES   dict로 4개 안내 전략을 제공:
               random    무작위 변수/값 (대조군, 비용 0)
               lp        LP 완화값이 가장 정수에 가까운 변수 (약 3ms/노드)
               lp_probe  전 변수 LP-probe로 강제변수를 건전하게 확정 (약 33ms/노드)
               model     MarginalNet의 최고 확신 변수 (약 1.6ms/노드)
    search(A, b, guide, model, device, time_limit, seed) -> (해결여부, 노드수, 소요초)
             전파를 먼저 적용하고, 확정된 변수를 접어넣은 뒤 안내 함수를 호출한다.
             계수가 전부 0인 행(축소 과정에서 생김)을 제거하는 처리가 포함되어 있다
             — SCIP가 빈 제약을 거부하므로 이 처리가 없으면 크래시한다.
  v22_cascade_search.py가 이 search()를 그대로 재사용한다.
